# Five-minute portfolio demo

1. Start DFIR Copilot and select **Load Safe Demo**.
2. Open **Evidence** and show the SHA-256 PASS state for all three items.
3. Open **Timeline** and filter High severity events.
4. Open **Findings** and explain the correlated download → PowerShell → network sequence.
5. Open **AI Copilot** and ask “How did this incident begin?”
6. Point out the artifact references and confidence score in the answer.
7. Open **Chain of Custody** and show import plus verification actions.
8. Generate the PDF report from **Reports & Exports**.

## Interview explanation

> DFIR Copilot is a local-first desktop forensic workbench. It preserves a copy
> of each evidence item, verifies SHA-256 integrity, extracts structured file
> and event artifacts, correlates them into a timeline, and generates a report.
> The Copilot is evidence-grounded: it must cite artifact IDs and returns
> insufficient evidence instead of inventing a conclusion.
